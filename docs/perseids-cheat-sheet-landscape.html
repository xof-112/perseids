Operator cheat sheet · 1/2 PERSEIDS

How to operate the module, what the OLED shows, and what each control does to the sound.

Bedienung, OLED-Anzeige und was jeder Regler soundtechnisch bewirkt.

IdeaIdee

Captures audio into up to five Trails, then builds a stereo sound cloud: Spectra (stylized additive) blended with Swarm (grains), plus Resonator, Filter, Reverb, Pan Drift and Crossfade.

Nimmt Audio in bis zu fünf Trails auf und baut eine Stereo-Klangwolke: Spectra (stilisiert additiv) gemischt mit Swarm (Grains), plus Resonator, Filter, Reverb, Pan Drift und Crossfade.

Multi Dry/Wet balances clean input vs. the finished cloud. Full wet = cloud only — dry is not fed into the FX.

Multi Dry/Wet mischt Clean-Input gegen die fertige Wolke. Voll wet = nur Cloud — Dry läuft nicht in die FX.

Home dashboardHome-Dashboard

Per Trail: level %, Lock (L), Solo (S), life bar (Hold countdown). Crossfade: thin focus ticks beside T#. Header: R1…R5 / REC1…REC5 (small type like CPU). Left: input VU + threshold.

Pro Trail: Level-%, Lock (L), Solo (S), Life-Bar (Hold-Countdown). Crossfade: schmale Fokus-Striche neben T#. Header: R1…R5 / REC1…REC5 (kleine Schrift wie CPU). Links: Input-VU + Threshold.

OLED CycleView: block name left, n/m top-right, value centered. Column width always matches a 4-slot page (2–3 params leave empty space; >4 scroll).

OLED CycleView: Blockname links, n/m oben rechts, Wert zentriert. Spaltenbreite immer wie 4er-Seite (2–3 Params: rechts leer; >4 scrollen).

OperationBedienung

  • Block pot — open menu; turn edits (pickup). Clearer turn on another pot jumps Block→Block (anti-jitter).
  • Block-Pot — Menü öffnen; Drehen editiert (Pickup). Klareres Drehen an anderem Pot = Block→Block (Anti-Jitter).
  • Cycle short — unused alone (except delete-all confirm).
  • Cycle kurz — allein unbenutzt (außer Delete-all bestätigen).
  • Cycle hold + pot / Multi — scroll list; column width always as for 4 slots.
  • Cycle halten + Pot / Multi — Liste scrollen; Spaltenbreite immer wie bei 4 Slots.
  • Cycle long — delete-all Trails (confirm).
  • Cycle lang — alle Trails löschen (Bestätigung).
  • Imprint short — Play / Pause.
  • Imprint kurz — Play / Pause.
  • Imprint long — Lock all active Trails (~800 ms; toggle; 2nd long unlocks Imprint locks only).
  • Imprint lang — alle aktiven Trails locken (~800 ms; Toggle; 2. Lang löst nur Imprint-Locks).
  • Rec — manual capture (same Overwrite rules as Threshold).
  • Rec — manuelle Aufnahme (gleiche Overwrite-Regeln wie Threshold).
  • Trail short on Home — Lock.
  • Trail kurz auf Home — Lock.
  • Trail short in a menu — Home (any of 5). Short again on Home = Lock.
  • Trail kurz im Menü — Home (einer von 5). Nochmal kurz auf Home = Lock.
  • Trail long — Solo (any screen).
  • Trail lang — Solo (jeder Screen).
  • Multi long push — Home.
  • Multi lang — Home.
  • Multi turn / push short — open / edit / step Multi menu.
  • Multi drehen / Push kurz — Multi öffnen / editieren / steppen.
  • Idle ~4 s — auto Home (for calm reading).
  • Idle ~4 s — auto Home (zum ruhigen Ablesen).

Trail encoders ×5Trail-Encoder ×5

  • Turn — loudness of that Trail in the mix.
  • Drehen — Lautstärke dieses Trails im Mix.
  • Short / Long — Lock on Home; Home from menus; Solo anywhere (see Operation).
  • Kurz / Lang — Lock auf Home; Home aus Menüs; Solo überall (siehe Bedienung).
