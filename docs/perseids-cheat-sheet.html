IdeaIdee

PERSEIDS captures audio into up to five Trails. From those it builds a stereo sound cloud: Spectra (stylized additive) blended with Swarm (grains), plus Resonator, Filter, Reverb, and spatial motion.

PERSEIDS nimmt Audio in bis zu fünf Trails auf. Daraus entsteht eine Stereo-Klangwolke: Spectra (stilisiert additiv) gemischt mit Swarm (Grains), plus Resonator, Filter, Reverb und räumliche Bewegung.

Multi Dry/Wet balances clean input against the finished cloud (equal-power; bus trim dry ×0.85 / wet ×1.30 so engines sit forward). Full wet = cloud only.

Multi Dry/Wet mischt Clean-Input gegen die fertige Wolke (Equal-Power; Bus-Trim Dry ×0.85 / Wet ×1.30, damit Engines präsenter sind). Voll wet = nur Cloud.

OperationBedienung

  • Block pot — opens that menu; turn edits the active parameter (pickup). From another open Block, a clearer turn on a different pot jumps to that Block (anti-jitter threshold).Block-Pot — öffnet das Menü; Drehen ändert den aktiven Parameter (Pickup). Aus einem anderen offenen Block: klareres Drehen an einem anderen Pot springt dorthin (mit Anti-Jitter-Schwelle).
  • Cycle short — while Multi/Settings open: next entry (same role as Cycle-hold+turn / broken Multi push). Elsewhere unused alone (except confirming delete-all).Cycle kurz — bei offenem Multi/Settings: nächster Eintrag (wie Cycle halten+drehen / defekter Multi-Push). Sonst allein unbenutzt (außer Delete-all bestätigen).
  • Cycle hold + pot / Multi turn — scroll the list without changing values. All blocks use the same column width (as if 4 slots); extra params slide; 2–3-param blocks don’t stretch wider.Cycle halten + Pot / Multi drehen — Liste scrollen ohne Werte zu ändern. Alle Blocks gleiche Spaltenbreite (wie 4 Slots); weitere Params scrollen; 2–3 Params werden nicht breiter.
  • Cycle long — delete-all Trails (confirm).Cycle lang — alle Trails löschen (Bestätigung).
  • Trail encoder short — on Home: Lock. In a Block/Multi menu: back to the Trail overview (Home); press short again on Home to Lock.Trail-Encoder kurz — auf Home: Lock. Im Block-/Multi-Menü: zurück zur Trail-Übersicht (Home); nochmal kurz auf Home = Lock.
  • Trail encoder long — Solo (from any screen).Trail-Encoder lang — Solo (von jedem Screen).
  • Imprint short — Play / Pause.Imprint kurz — Play / Pause.
  • Imprint long — Lock all active Trails (~800 ms hold; toggle; second long unlocks only what Imprint locked).Imprint lang — alle aktiven Trails locken (~800 ms; Toggle; zweites Lang löst nur Imprint-Locks).
  • Multi long push — Home.Multi lang — Home.
  • Rec — manual capture (same round-robin / Overwrite rules as Threshold).Rec — manuelle Aufnahme (gleiche Round-Robin-/Overwrite-Regeln wie Threshold).
  • Idle (~7 s) — automatic return to Home (for reading calmly; not needed for jumping menus).Idle (~7 s) — automatisch zurück zu Home (zum ruhigen Ablesen; nicht nötig zum Menü-Springen).

On the OLED: block name top-left, position n/m (and optional CPU%) top-right, value centered above the bars, abbreviations in the bottom segmented row (active cell inverted). Columns always use the same width as a 4-slot page — blocks with only 2–3 params leave empty space on the right; blocks with more than four scroll the row.

Auf dem OLED: Blockname oben links, Position n/m (und optional CPU%) oben rechts, Wert zentriert über den Balken, Abkürzungen unten in der Segmentzeile (aktive Zelle invertiert). Spalten haben immer die Breite einer 4er-Seite — bei nur 2–3 Params bleibt rechts Platz leer; bei mehr als vier scrollt die Zeile.

Named-pole header hints (small type beside the value): SP/SW (Blend), SA/FO (Waveshape), UM/AU (Umbra/Aurora), BL/RD (Atmosphere), CH/FR (Character). Below 50% the left pole sits before the number; above 50% the right pole after it; at center neither. While a pole hint shows, % is dropped so the label cannot overwrite it — Pitch and Velocity stay plain ±%.

Pol-Hinweise im Header (kleine Schrift neben dem Wert): SP/SW (Blend), SA/FO (Waveshape), UM/AU (Umbra/Aurora), BL/RD (Atmosphere), CH/FR (Character). Unter 50% steht der linke Pol vor der Zahl, darüber der rechte danach; in der Mitte keiner. Solange ein Polhinweis sichtbar ist, entfällt das %, damit das Kürzel es nicht überschreibt — Pitch und Velocity bleiben normales ±%.

Load governor: L! immediately left of the CPU figure (L!C42) means the module is temporarily running fewer Swarm grains to keep the audio from breaking up. The SDRAM figure is hidden while it shows, and the cloud sounds slightly thinner. The marker disappears on its own once the load drops.

Load-Governor: L! direkt links vom CPU-Wert (L!C42) heißt: Das Modul fährt vorübergehend weniger Swarm-Grains, damit die Audio-Wiedergabe nicht abreißt. Der SDRAM-Wert wird solange ausgeblendet, und die Wolke klingt etwas dünner. Der Marker verschwindet von selbst, sobald die Last sinkt.

Multi

Big encoder. Turn to open / edit. Cycle short or Cycle hold + Multi turn steps the list (Multi push deferred on current hardware). Long Multi push → Home when push works; else Trail push / idle ~7 s. Landing on SET opens the Settings submenu.

Großer Encoder. Drehen = öffnen / editieren. Cycle kurz oder Cycle halten + Multi drehen stept die Liste (Multi-Push auf aktueller Hardware unzuverlässig). Langer Multi-Push → Home, falls Push geht; sonst Trail-Push / Idle ~7 s. Auf SET landet man im Settings-Untermenü.
