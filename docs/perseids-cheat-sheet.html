IdeaIdee

PERSEIDS captures audio into up to five Trails. From those it builds a stereo sound cloud: Spectra (stylized additive) blended with Swarm (grains), plus Resonator, Filter, Reverb, and spatial motion.

PERSEIDS nimmt Audio in bis zu fünf Trails auf. Daraus entsteht eine Stereo-Klangwolke: Spectra (stilisiert additiv) gemischt mit Swarm (Grains), plus Resonator, Filter, Reverb und räumliche Bewegung.

Multi Dry/Wet balances clean input against the finished cloud. Full wet = cloud only.

Multi Dry/Wet mischt Clean-Input gegen die fertige Wolke. Voll wet = nur Cloud.

OperationBedienung

  • Block pot — opens that menu; turn edits the active parameter (pickup). From another open Block, a clearer turn on a different pot jumps to that Block (anti-jitter threshold).Block-Pot — öffnet das Menü; Drehen ändert den aktiven Parameter (Pickup). Aus einem anderen offenen Block: klareres Drehen an einem anderen Pot springt dorthin (mit Anti-Jitter-Schwelle).
  • Cycle short — unused alone (except confirming delete-all). Not for next parameter / not for Multi.Cycle kurz — allein unbenutzt (außer Delete-all bestätigen). Nicht für nächsten Parameter / nicht für Multi.
  • Cycle hold + pot / Multi turn — scroll the list without changing values. Blocks with more than four params keep 4-wide columns; the row slides (header shows n/m).Cycle halten + Pot / Multi drehen — Liste scrollen ohne Werte zu ändern. Bei mehr als vier Params bleiben 4 Spalten breit; die Zeile scrollt (Header zeigt n/m).
  • Cycle long — delete-all Trails (confirm).Cycle lang — alle Trails löschen (Bestätigung).
  • Trail encoder short — on Home: Lock. In a Block/Multi menu: back to the Trail overview (Home); press short again on Home to Lock.Trail-Encoder kurz — auf Home: Lock. Im Block-/Multi-Menü: zurück zur Trail-Übersicht (Home); nochmal kurz auf Home = Lock.
  • Trail encoder long — Solo (from any screen).Trail-Encoder lang — Solo (von jedem Screen).
  • Imprint short — Play / Pause.Imprint kurz — Play / Pause.
  • Multi long push — Home.Multi lang — Home.
  • Rec — manual capture (same round-robin / Overwrite rules as Threshold).Rec — manuelle Aufnahme (gleiche Round-Robin-/Overwrite-Regeln wie Threshold).
  • Idle (~4 s) — automatic return to Home (for reading calmly; not needed for jumping menus).Idle (~4 s) — automatisch zurück zu Home (zum ruhigen Ablesen; nicht nötig zum Menü-Springen).

On the OLED: block name top-left, position n/m (and optional CPU%) top-right, value centered above the bars, abbreviations in the bottom segmented row (active cell inverted; at most four columns visible).

Auf dem OLED: Blockname oben links, Position n/m (und optional CPU%) oben rechts, Wert zentriert über den Balken, Abkürzungen unten in der Segmentzeile (aktive Zelle invertiert; höchstens vier Spalten sichtbar).

Block potsBlock-Pots

1

Trails

Pot 1

How many voices live in the cloud, and when recording starts.

Wie viele Stimmen in der Wolke leben, und wann aufgenommen wird.

ParamOLEDExpectErwartung
Count CNT 1–5 Trails. Fewer = thinner; more = denser stack.1–5 Trails. Weniger = dünner; mehr = dichterer Stack.
Threshold THR How loud input must be to auto-record. Lower = more sensitive.Wie laut der Input für Auto-Aufnahme sein muss. Niedriger = empfindlicher.
Cont. Rec CRE OFF = rising edge only (cross below→above). ON = keep arming while above threshold.OFF = nur Rising Edge (unter→über THR). ON = weiter armieren solange über Threshold.
Overwrite OVR ON (default) = Empty first, else replace oldest unlocked Trail even mid-Hold. OFF = wait for Empty (finite Hold/Fade protected; INF still replaceable). Applies to Threshold, CRE, and Rec.ON (Default) = zuerst Empty, sonst ältesten ungelockten Trail ersetzen — auch mitten in Hold. OFF = auf Empty warten (finite Hold/Fade geschützt; INF weiter ersetzbar). Gilt für Threshold, CRE und Rec.
On/Off ON Capture system on or off.Aufnahmesystem an oder aus.

Time

Wie lang jede Aufnahme ist, wie lange sie bleibt, wie sie atmet.

ParamOLEDExpectErwartung

Engines

Pot 3

Balance the two engines and their pitch. On BLD the small hint SP/SW shows which side you’re on.

Balance der beiden Engines und deren Pitch. Bei BLD zeigt der kleine Hinweis SP/SW die Seite.

ParamOLEDExpectErwartung
Blend BLD Toward Spectra (SP) or Swarm (SW). Middle = both.Richtung Spectra (SP) oder Swarm (SW). Mitte = beides.

Spectra

Pot 5

Stylized harmonic body — character resynthesis, not a transparent freeze.

Stilisierter Harmonik-Körper — Charakter-Resynthese, kein transparentes Freeze.

ParamOLEDExpectErwartung
Partials PAR Fewer = simpler. More = denser harmonic stack.Weniger = einfacher. Mehr = dichtere Harmonik.
Waveshape WSH Center = sine · left = saw-ish · right = fold / harsh.Mitte = Sinus · links = sägeartig · rechts = Fold / scharf.
Umbra / Aurora UMB Left = airy (Umbra). Right = vocal/formant (Aurora). Center = neutral.Links = luftig (Umbra). Rechts = vokal/Formant (Aurora). Mitte = neutral.
Ensemble / Drift ENS Organic chorus / detune shimmer.Organischer Chorus / Detune-Schimmern.

Swarm

Pot 4

Granular texture — the cloudy, moving half of the blend.

Granulare Textur — die wolkige, bewegte Hälfte des Blends.

ParamOLEDExpectErwartung
Size SIZ Short grains = bustling. Long = smeared pad.Kurze Grains = geschäftig. Lang = verschmiertes Pad.
Spread SPR Stereo width of the grains.Stereobreite der Grains.
Scan SCN 0 = freeze in the buffer. Up = scrub through the take.0 = Freeze im Buffer. Aufdrehen = durch die Aufnahme scrubben.
Direction DIR Fwd · Rev · Rnd — grain playback direction (Rnd = coin flip per grain). Scan scrub is separate.Fwd · Rev · Rnd — Grain-Spielrichtung (Rnd = Münzwurf pro Grain). Scan-Scrub ist unabhängig.
Atmosphere ATM Left = Blur (soft). Right = Radiation (lo-fi / warble).Links = Blur (weich). Rechts = Radiation (Lo-Fi / Warble).

Trail encodersTrail-Encoder

  • Turn — loudness of that Trail.Drehen — Lautstärke dieses Trails.
  • Short on Home — Lock (L) — no overwrite, no hold fade-out.Kurz auf Home — Lock (L) — kein Überschreiben, kein Hold-Fade-Out.
  • Short in a menu — Home — any of the five pushes returns to the Trail overview; short again on Home to Lock.Kurz im Menü — Home — jeder der fünf Pushes zurück zur Trail-Übersicht; nochmal kurz auf Home = Lock.

Multi

Big encoder. Turn to open / edit. Multi push short steps the list (or Cycle hold + Multi turn). Long Multi push → Home.

Großer Encoder. Drehen = öffnen / editieren. Multi-Push kurz steppt die Liste (oder Cycle halten + Multi drehen). Langer Multi-Push → Home.

ParamOLEDExpectErwartung
Dry / Wet DW Dry = clean input. Wet = full cloud.Dry = Clean-Input. Wet = volle Wolke.
Macro1 / Macro2 M1 M2 Reserved — not wired yet.Reserviert — noch nicht verdrahtet.
Time Unit TU Reserved — Seconds vs Clock (later).Reserviert — Sekunden vs. Clock (später).
